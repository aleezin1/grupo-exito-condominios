## Projeto: Desenvolvimento de Página Web - Gestão Condominial

**Curso:** Engenharia de Software  
**Tecnologias:** HTML5 e CSS

### 1. Objetivo do Projeto

Desenvolver uma página web voltada à gestão condominial, aplicando conhecimentos de HTML, CSS e JavaScript para construir uma interface organizada, intuitiva e funcional.

### 2. Etapas do Desenvolvimento

| Etapa | Atividades realizadas |
|-------|-----------------------|
| 1. Planejamento | Definição do tema, conteúdo e estrutura da página. |
| 2. HTML | Criação do cabeçalho, menus, seções, formulários e rodapé. |
| 3. CSS | Aplicação de cores, fontes, espaçamentos e alinhamentos. |
| 4. Testes | Verificação dos elementos e correção de erros visuais. |
| 5. Finalização | Revisão do código e organização dos arquivos. |

### 3. Dificuldades Encontradas

- Alinhamento e posicionamento dos elementos.
- Organização das seções e dos conteúdos.
- Padronização visual dos componentes.
- Ajustes de espaçamento e responsividade.

### 4. Soluções Aplicadas

Foram realizados testes e ajustes nas propriedades CSS, utilizando recursos como `display: flex`, `justify-content`, `align-items` e `gap`, além da revisão da estrutura HTML.

### 5. Resultados e Aprendizados

O desenvolvimento permitiu aplicar conceitos fundamentais de Front-End, aprimorando conhecimentos sobre estruturação de páginas, estilização, organização de código e resolução de problemas.

### 6. Considerações Finais

O projeto contribuiu para o desenvolvimento de habilidades práticas em HTML e CSS, demonstrando a importância do planejamento, da organização e dos testes na construção de interfaces web.
